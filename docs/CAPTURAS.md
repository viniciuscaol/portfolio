# Captura da API de ECG WXML

A imagem `assets/projects/ecg-wxml-viewer.jpg` é uma captura da área do visualizador web da aplicação em execução local, não uma ilustração nem um exame real.

- Código: [api-ecg-wxml](https://github.com/viniciuscaol/api-ecg-wxml/tree/0ed2cbd37fe77ebb71bf2460fdf51e1b774d7e09).
- Commit da aplicação: `0ed2cbd37fe77ebb71bf2460fdf51e1b774d7e09`.
- Entrada: `examples/synthetic.wxml` do mesmo commit, com identificação explícita de paciente de teste sintético.
- Configuração: SVG, layout contínuo, registro 1, início 0, grade cinza e zoom ajustado à largura (100%).
- Captura realizada em 04/11/2026, após enviar o arquivo pela interface e concluir a conversão.
- A imagem registra o início do visualizador; as demais derivações podem ser percorridas na aplicação. O recorte do cartão serve apenas como prévia.
- Não foram usados dados de pacientes reais, credenciais ou informações internas.

## Reproduzir

1. Obter o commit indicado do repositório da API e executar a aplicação conforme seu README.
2. Abrir a interface, selecionar `examples/synthetic.wxml` e manter as opções acima.
3. Clicar em **Visualizar / gerar** e aguardar o traçado.
4. Clicar em **Ajustar largura** e capturar a área do visualizador, incluindo os controles e a identificação sintética.
5. Conferir a imagem antes de substituir o arquivo do portfólio.

A captura documenta o funcionamento técnico com essa amostra. Não demonstra interpretação diagnóstica, homologação clínica ou compatibilidade com todos os formatos de exame.
